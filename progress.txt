## Codebase Patterns
- "use node" is file-level in Convex — all functions in a file (mutations + actions) run in node runtime if "use node" is present; this is intentional and fine
- Convex actions call mutations in the same file via `makeFunctionReference<"mutation">("filename:mutationName")`
- AWS SDK must be installed explicitly: `npm install @aws-sdk/client-s3`; it is not bundled by default
- Server actions (Next.js) for triggering Convex actions use `client.action(makeFunctionReference<"action">("module:fn"), {})` from `createConvexHttpClient()`
- Admin page role checks use `session.user.role === "super_admin"` from `getServerAuthSession()` (next-auth)
- Convex compound index query: use `.withIndex("by_order_id", ...).filter(q => q.eq(q.field("class_id"), value))` for compound lookups when no compound index exists
